04

Build & install

Clone, make, done — or use the Create App to write an install USB key.

$ git clone https://github.com/chris1111/HP-EliteBook-840-G4.git && cd $HOME/HP-EliteBook-840-G4 && make
zsh — HP-EliteBook-840-G4
$ make
Ready — press “Run build”.
Xcode build · Big Sur → Tahoe

Build instructions apply to macOS Big Sur through Tahoe, using the BCM94360NG Wi-Fi card.

Before post-installing macOS Tahoe, read the Post-Install Readme ↗ — it matters.
